# AR-0008: Formal upgrade and recovery model

Extend the TLA+ contract with upgrade phases, quiescence, backup validity,
staged replacement, postcondition validation, rollback, crash recovery, and
reopen admission. Connect every invariant to implementation tests and retain
the explicit proof boundary around Python, Git, filesystems, and arbitrary
external commands.

Add exhaustive bounded fault and multiprocess tests for every phase transition,
including repeated interruption and recovery.
