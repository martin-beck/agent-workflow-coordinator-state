2. Add one idempotent provisioning helper that creates the authority fence, control store, control binding, and baseline session with fsync/identity checks.
3. Invoke it only after SQLite authority creation/import succeeds, with recoverable cleanup on failure.
4. Make Git-to-SQLite migration use the same helper and preserve the old Git authority until all new artifacts validate.
5. Add hostile tests for partial files, aliases, process death, duplicate provisioning, and baseline writer behavior.
6. Run all local/hosted/post-merge gates and reconcile the AR.
