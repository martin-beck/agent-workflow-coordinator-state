# AR-0046: Wire verified backup into the upgrade engine

1. Inspect `UpgradeEngine` phase and journal contracts and select the narrowest
   backup-only injection point.
2. Define an immutable, session-bound backup capability that cannot execute commit,
   selector publication, stage, or rollback.
3. Invoke `execute_verified_backup` from the backup phase and persist its evidence
   through the existing journal contract.
4. Add hostile tests for forged capabilities, stale barriers, duplicate invocation,
   backend mismatch, and failure cleanup.
5. Run full quality/formal/hosted/post-merge gates; keep apply and rollback rejecting.
