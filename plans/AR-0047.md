1. Audit the existing runtime admission, manifest, digest, and fixed-entrypoint
   contracts on exact product main; identify the smallest non-overlapping
   read-only stage seam.
2. Specify the generated `backend.stage` operation and immutable context
   binding, including artifact-root containment, ownership, regular-file and
   symlink rejection, source/runtime digest binding, and fencing identity.
3. Implement the capability behind `UpgradeEngine`'s stage phase only. Keep
   commit/apply/rollback and selector publication explicitly rejected.
4. Add hostile tests for every failure path, including replacement and uncertain
   reads, and map only the implemented model transition to executable evidence.
5. Run focused tests, the complete suite, Ruff, mypy, and branch coverage at or
   above 95%; publish an exact-head PR with DCO and require green hosted gates.
6. Merge only after exact-head review; require post-merge Formal and Verify,
   then reconcile and run `handoffctl doctor --live` before closing the AR.
