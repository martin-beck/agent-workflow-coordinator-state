# AR-0106: Repair branch-coverage qualification

Repair the repository-wide branch-coverage qualification exposed while independently reviewing AR-0104. Add behavioral tests for genuinely unexercised safety and production-binding branches; do not weaken the threshold, omit files, or claim a passing gate from local-only evidence.

The continuation is a prerequisite to merging AR-0104. It does not implement Git production resolution (AR-0105) or phase mutation/orchestration (AR-0102).

Acceptance requires the exact pushed candidate SHA, a successful hosted `verify.yml` run at the configured 95% branch threshold, independent review of that exact SHA, and reconciled state.
