# AR-0024: Discussion pause and reconciliation enforcement

Add the lifecycle barrier after an interaction packet is emitted and before
implementation work can resume. Define accepted, rejected, clarify, and
user-added-option event shapes; require AWG reconciliation references and AWQ
pass evidence; and make stale responses harmless.

Acceptance requires crash/recovery, duplicate response, stale response,
contradiction, and unresolved-dependent-task tests.
