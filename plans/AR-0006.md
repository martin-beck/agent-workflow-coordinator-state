# AR-0006: SQLite backup, migration, and restore

Implement the SQLite-specific upgrade boundary: online backup of the database
and WAL/SHM state, integrity checks, migration equivalence, atomic selector
changes, and restore to the previous authoritative database.

Test busy writers, stale leases, crash between preparation and selector switch,
projection failure, corrupt or incomplete backups, and rollback after a
post-migration failure. Never copy only the main database file while writers
are active.
