# AR-0009: Release integration and first upgrade

Integrate generated upgrade contracts into release CI and documentation.
Require exact release identity, generated-step completeness, backup/restore
fixtures and fresh-clone validation before publication. External review is
optional supplementary evidence, never a publication prerequisite.

Perform the first supported upgrade from the previous coordinator release to
the new release in isolated Git and SQLite fixtures, including forced failures
at every step and successful recovery to a functional state.
