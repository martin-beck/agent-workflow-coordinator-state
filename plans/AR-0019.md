# AR-0019: Fast merge formal tier and weekly exhaustive run

Define separate formal tiers: a small bounded required merge/commit check and
a complete weekly/dispatch run with a several-hour timeout that is advisory for merges but still produces
durable, inspectable evidence. Preserve release-sensitive publication gates,
exact-head attestations, model-set declarations, and truthful non-claims.

Acceptance requires workflow and branch-protection tests, tier-specific
attestation/profile tests, explicit failure/timeout semantics, and independent
review of the resulting merge and weekly quality policy.
