# AR-0011: Bounded TLA+ execution and admission safety

Implement a fail-closed, bounded execution path for every coordinator TLC model. Keep the existing
models, configurations, pinned tool provenance and evidence claims unchanged unless a contract change
is independently justified.

Acceptance criteria:

- every coordinator TLC invocation has explicit worker and JVM heap bounds;
- invocations use the shared host admission boundary and cannot bypass it accidentally;
- queueing is durable enough to survive a caller interruption and does not stop existing workers;
- per-job cgroup memory and swap limits contain failures to the formal job;
- focused positive, queueing, cancellation and memory-limit tests pass;
- exact-head review, signed DCO commit, CI and post-merge verification are complete.
