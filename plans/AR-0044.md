# AR-0044: Implement authority-neutral preflight and backup phase

1. Define a typed session and verified-backup record shared by Git and SQLite.
2. Bind the record to the existing barrier/fence and authenticated runtime identity.
3. Implement preflight and backup orchestration using existing `git_backup` and
   `sqlite_backup` primitives, with explicit fsync and identity rereads.
4. Persist only privacy-safe digests and state transitions; never publish a selector.
5. Add independent-process and injected-failure tests for every durability boundary.
6. Add bounded formal correspondence and non-claims, then run all quality/hosted/
   post-merge gates. Keep apply/rollback rejection-only.
