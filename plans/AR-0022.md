# AR-0022: Mandatory oracle interaction-gate lifecycle

Define typed task events and lifecycle transitions for AWG's intake review,
discussion, formal-spec review, and reconciliation gates. Bind each event to
the task revision and public-safe artifact digests while retaining Coordinator
authority over claims, leases, dependencies, and state transitions.

Acceptance requires bounded formal evidence, migration compatibility, exact
rejection semantics, and a locally reproducible assessment of the AWG/AWQ
ownership boundary. External review is optional supplementary evidence.
