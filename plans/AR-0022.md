# AR-0022 plan: bounded actionable state projection

## Scope

Provide an upstream coordinator implementation for the bounded actionable-state
projection required by downstream coordination consumers. The projection must
retain the complete authoritative task state while emitting only the documented
bounded actionable statuses for the compact current view. It must be a normal
upstream release change so downstream vendor synchronization can consume it
without hand-editing a vendored file or rewriting a manifest digest.

## Acceptance

- Identify and document the public projection contract and its status allowlist.
- Implement the bounded projection in the coordinator product, preserving
  deterministic ordering, dependency information, and fail-closed behavior for
  unknown or malformed status values.
- Add positive and negative unit/integration tests, including a regression test
  proving completed historical tasks cannot expand the compact actionable view.
- Run the coordinator's focused and full quality gates, independent review,
  signed conventional DCO commit, exact-head hosted checks, and post-merge
  verification.
- Publish an immutable coordinator release containing the fix, then provide the
  exact release tag/commit and vendor-sync evidence to downstream consumers.

## Non-goals

Do not patch downstream vendored files, rewrite a downstream vendor manifest,
weaken release/signature gates, or change task authority semantics outside the
projection contract.
