# AR-0104: Construct production live upgrade binding

## Objective

Connect the command boundary to the canonical durable coordinator state. The production caller must construct `LiveUpgradeBinding` itself from the current control/session/fence state; a caller-supplied object or path-only identity is not sufficient.

## Scope

- implement a narrow runtime-state resolver owned by handoffctl;
- bind the selected backend, durable session, lock-domain scope, lease, recheck, and adapter;
- reject missing, released, ambiguous, stale, foreign, and process-death state before phase construction;
- leave actual phase execution to AR-0102.

## Completion

Require independent exact-head review, hosted checks, fresh downstream consumption, post-merge verification, and reconciled state evidence. Do not close AR-0009 or AR-0031 on resolver tests alone.
