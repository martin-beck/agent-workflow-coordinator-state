   including human and JSON output, Git and SQLite projections, and vendored
   downstream documentation.
2. Specify `short_title` grammar and the exact four-word counting rule. Define
   legacy compatibility, explicit migration, validation errors and privacy
   boundaries before changing the schema.
3. Add the schema, storage and migration support without altering lifecycle
   transitions, revisions, ownership or dependency admission.
4. Populate reviewed short titles for all maintained Coordinator task records;
   keep full `title` and `summary` as the detailed descriptions.
5. Render `AR-#### — short title` consistently in active command responses,
   snapshots, queue/status views and worktree/board displays. Keep JSON fields
   structured rather than embedding presentation text.
6. Add focused hostile validation, legacy migration, parity, projection,
   privacy and command-output tests. Verify that no title influences a
   mutation decision.
7. Run full deterministic and applicable formal gates, merge signed+DCO work,
   and record exact-main and downstream vendor evidence.
