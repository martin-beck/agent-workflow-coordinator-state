# AR-0101: Production upgrade command and session binding

Connect the validated contract/runtime binding to a live durable barrier
session, concrete Git or SQLite authority adapter, and UpgradeEngine journal.
The command must construct the exact generated phase operations and bounded
commit/rollback capabilities from current state rather than accepting caller
callbacks, synthetic evidence, or path-only identities.

Keep unsupported phases fail-closed and classify process death, stale session,
authority replacement, journal ambiguity, and uncertain effect outcomes into
durable safe mode. Require independent review, hosted checks, post-merge
verification, and reconciliation. The AI-generated model remains best-effort
guidance; no source-to-model refinement proof or authorization prerequisite is
required.
