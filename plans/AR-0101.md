# AR-0101 plan: reduced liveness model and coverage mapping

Measure the state dimensions driving the liveness cross product, then create a
small named configuration that retains the required transitions and fairness
semantics. Record a reviewable bounded coverage argument for every reduced
dimension; it is explicitly not a proof that source code refines the model.
Keep the large configuration intact as stress exploration, but do not call it
a release gate. Exercise the model, mapping validator, and time-budget
regression in deterministic tests.
