# AR-0005: Git-backend backup and restore

Implement complete Git-backend backup and restore: immutable state commit and
refs, task and plan files, generated views, binding/backend/profile files,
vendor manifest and runtime metadata, with privacy-safe backup indexing.

Verify the backup in a clean temporary checkout before replacing anything.
Exercise interrupted staging, failed rename, corrupt backup, failed commit,
failed push, and rollback while preserving unrelated product history and task
records.
