The formal workflow currently scopes `TLC_ADMISSION_QUEUE` and
`TLC_ADMISSION_LOCK` only to the bounded model invocation. A later unittest
step can therefore fall back to the root-owned `/tmp` admission path and fail
before runner contract tests execute. Define private absolute paths once at
job scope and retain the existing explicit verifier arguments. Add regression
coverage for propagation and fail-closed path privacy. This repair must not
change `handoffctl`, models, resource bounds, or any quality gate.
