Qualify the reusable workflow with a deterministic mocked issue journey:
reviewed decomposition creates all ARs, the initial map is published, members
complete in dependency order with one update each, and only the finalizer
closes once with complete evidence. Exercise retry, timeout, duplicate
delivery, restart, reopen, supersession, manual conflicts and invalid
finalizer paths. Document operation, permissions, privacy, migration and
recovery. This test AR never closes a real issue.
