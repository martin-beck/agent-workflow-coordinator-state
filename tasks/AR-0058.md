## Objective

Finish the selector/runtime boundary so validation remains bound to the exact
runtime descriptor eventually executed, with atomic publication and explicit
ambiguity recovery.

## Acceptance evidence

- Immutable bootstrap and offline complete runtime staging are preserved.
- Selector syntax, ownership/modes, allowlist, manifest, commit/tag identity,
  signature/trust policy, and project binding are validated.
- Descriptor-bound no-follow read-until-EOF logic defeats symlink, hard-link,
  ancestor, pathname, and validation-to-exec replacement races.
- Atomic publication, directory fsync, partial staging, process death, and
  ambiguous fsync recovery are tested in subprocesses.
- Only a retained validated descriptor may dispatch; otherwise the known-good
  runtime continues or the operation rejects without dispatch.
