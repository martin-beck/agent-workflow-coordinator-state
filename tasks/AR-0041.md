## Objective

Provide a stable, selector-aware launcher seam that revalidates the retained authenticated runtime and returns/executes only the fixed runtime entrypoint. Caller input may provide arguments, never a runtime path or script path.

## Acceptance evidence

- Fixed entrypoint is bounded and cannot escape the retained runtime directory.
- Selector, manifest, directory, and descriptor identity are revalidated immediately before dispatch.
- Replacement, symlink, hard-link, path-escape, and caller-selected-entrypoint attempts fail closed.
- Subprocess tests prove normal and selected-runtime invocations bind to the exact retained release.
- Full quality, formal, hosted, post-merge, and state reconciliation gates pass.
