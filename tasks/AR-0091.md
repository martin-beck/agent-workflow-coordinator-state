## Objective

Make Coordinator the durable control plane for long-running autonomous development:
an agent receives a narrow work contract, records observable progress, detects
drift and staleness, resumes safely, stops non-progress loops, and coordinates
work across sessions. This is usable by a single developer; no feature in this
series requires a second human, account, or external reviewer.

## Release boundary

All children are required for the next feature release. Each child remains a
separately reviewable and releasable state transition; this parent may not be
completed while a child is open.
