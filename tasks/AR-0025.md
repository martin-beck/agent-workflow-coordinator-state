# AR-0025

Restore the coordinator's bounded project observation contract for linked
worktrees in both the configured product repository and the bound state
repository. The v0.3.50 implementation scans only the product checkout,
which makes state-task worktrees invisible to ownership, dirty-tree and
exact-head safety checks used by ASB.

The repair must deduplicate shared paths, preserve detached-head and dirty-path
observations, remain privacy-safe and bounded, and fail closed on unavailable
or malformed Git observations. Do not weaken the state-worktree requirement or
change release/vendor manifests in place.

Acceptance requires focused positive/negative tests, the full coordinator
quality suite, lint/type/privacy/formal gates applicable to the change,
independent exact-head review, signed+DCO history, green hosted checks, an
immutable release, and fresh-clone verification. Downstream consumers must
adopt only the resulting exact released commit.
