## Objective

Make newly provisioned SQLite installations use the durable barrier-aware mutation routes by default. Preserve legacy pre-marker installations as readable and writable, but do not allow them to start upgrades.

## Acceptance evidence

- SQLite init and Git-to-SQLite migration atomically provision authority marker/lifecycle/lock, control store/binding, and a uniquely identifiable released baseline session.
- Partial provisioning, replacement, aliasing, corrupt records, and process death fail closed without losing the existing authority.
- A released baseline permits ordinary writes through AR-0038; a held/releasing/ambiguous session rejects them.
- Fresh-install and migration tests cover restart and rollback-safe cleanup.
- Full quality/formal/hosted/post-merge gates and state reconciliation pass.
