## Problem statement

A fresh clone of exact Coordinator-state main
`d60e406279594d9c839fcbbafdb95526f0952bae` fails
`python3 tools/handoffctl_vendor.py verify --target .`. Tracked commit
`183cbaad0303b3494f2c6e82acc3d5b8cdd80bac` changed vendored
`tools/handoffctl.py` and `tests/test_handoffctl.py` directly for TUI session
handoffs without updating the immutable vendor manifest or first landing the
runtime change in the upstream Coordinator product.

The manifest expects SHA-256 `34fd052e...` for `tools/handoffctl.py` and
`067e7582...` for `tests/test_handoffctl.py`, while exact main contains
`3aa42cae...` and `1048a72e...`. Updating two digest strings would falsely
legitimize a downstream fork and omit the complete runtime/schema/formal/vendor
closure. Reverting blindly could remove behavior consumed by downstream UI
work. The repair therefore requires an explicit upstream migration and official
vendor synchronization.

  Coordinator AR with strict schema, privacy, lifecycle, storage-backend,
  migration, rollback, doctor, and formal coverage. Project-specific oracle or
  UI policy must remain downstream and must not patch vendored files.
- Independently review and merge the upstream exact tree with SSH signature,
  matching DCO, full deterministic/formal gates, hosted CI, signed local merge,
  and exact-main post-merge verification.

  `vendor.py sync-development` path into an isolated exact Coordinator-state
  candidate. Verify every destination/source, blob, mode, SHA-256, manifest
  field, commit and tree. No manual digest refresh or partial copy is allowed.
- Preserve state binding, backend, profile, tasks, plans, directives and
  project-specific files byte-for-byte except deterministic generated views.
- Add a regression proving any tracked modification to a declared vendor file
  makes state CI fail before publication, and ensure the repository's required
  hosted check always runs vendor verification.
- Run the complete state tests, schemas, headers, privacy/secret/size checks,
  generated-view checks, formal tiers, reconciliation, snapshot, and live
  doctor from a clean checkout.
