Objective: make the Git production factory capable of a truthful full sequence.

The current commit capability requires a pre-staged change, while the existing
stage adapter is intentionally read-only and Git admission requires a clean
authority. This AR supplies the missing capability without moving mutation into
public dispatch or an unjournaled handler.

Acceptance evidence: a typed operation identity bound to the admitted Git
session; durable intent before any filesystem/index/ref mutation; clean-state,
branch/head, path, and fencing rechecks; injected failure and process-death
classification; real eight-phase Git factory execution; independent review,
hosted/post-merge checks, and reconciled state.
