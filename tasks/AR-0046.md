## Objective

Make the verified backup operation reachable from the bounded upgrade engine phase
path, while keeping all selector publication, staging, commit, apply, and rollback
operations disabled.

- `UpgradeEngine` receives an immutable authority-neutral backup capability only
  after barrier/session identity and backend binding are rechecked.
- The backup phase invokes the common executor exactly once and records its verified
  result in the existing phase journal.
- Missing, stale, forged, replaced, or ambiguous session context rejects before any
  backup effect; failure leaves the coordinator usable and write-closed as required.
- Existing handler-based tests and generated Git/SQLite backup tests remain green.
- Formal evidence maps only the backup transition; no refinement or mutation gate
  overclaim is introduced.
