Implement the `handoffctl` GitHub publication boundary for an approved
issue-series manifest. It posts one concise initial issue comment listing the
series, member AR IDs/titles/dependencies, finalizer and stable correlation
token. Bind configured repository and exact issue identity, verify the issue
is open, use idempotency receipts, and fail closed on ambiguous, unavailable,
unauthorized, moved or mismatched hosted state. GitHub remains a projection;
the manifest is authoritative. No token, raw response, issue body, private
path or command log may enter state.
