## Objective

Ensure every production SQLite mutation route acquires the adapter-owned common -> control -> authority scope and rereads the durable barrier before opening the authority transaction. Read-only inspection and legacy Git operation must remain functional.

## Acceptance evidence

- `handoffctl` mutation, command-result, observation, migration, and retirement routes use a bound `SQLiteBackend` or fail closed when the compatibility marker/control store is absent.
- No public route can silently construct an unbound mutating SQLite backend.
- Provisioned released state remains writable; held, releasing, ambiguous, missing, corrupt, replaced, or foreign control state is rejected with the stable fence error.
- Independent-process tests cover each route and process-death/control-store replacement boundaries.
- Full local quality gates, hosted PR gates, exact-head post-merge Verify, and state reconciliation pass.
