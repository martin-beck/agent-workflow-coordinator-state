## Objective

Replace the current rejection-only authority mutation seam with a separately
gated, bound capability only when its Git and SQLite failure matrix and formal
refinement obligations are complete. No release or rollback mutation is
authorized by this AR.

## Acceptance evidence

- One immutable admission bundle binds session, authority, selector, runtime,
  artifact, and fencing identities before and after each effect.
- Git and SQLite commit/apply behavior is independently covered for all
  process-death, fsync, close, stale-owner, reopen, retry, and ambiguity
  boundaries.
- Failure leaves the old coordinator functional or enters explicit safe mode;
  no ambiguous effect is reported as success.
- Exact-head hosted Formal and Verify checks, formal evidence-map updates, and
  independent review pass before any mutation gate is enabled.
