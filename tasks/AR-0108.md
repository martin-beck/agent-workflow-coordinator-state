Implement an optional `handoffctl` GitHub publication adapter for an approved
series. A live posting attempt uses configured credentials when available;
deterministic mock and dry-run transports require neither network nor
authentication. Bind a requested live attempt to configured repository and
exact issue identity, use receipts and idempotency, and record unavailable,
unauthorized, moved, ambiguous, or mismatched hosted effects as retryable
deferred projections. Such effects never block local AR lifecycle progress,
acceptance, release, or closure. GitHub remains a projection; the manifest is
authoritative. No token, raw response, issue body, private path, or command log
enters state.
