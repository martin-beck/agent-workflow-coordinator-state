ASB AR-1826 is blocked because Coordinator v0.7.5 retains a non-empty
`worktree_key` while `branch` is empty, and `bind-worktree` correctly refuses
to guess whether that key is still authoritative. No supported lifecycle
command can clear this partial legacy pair.

Add one narrowly scoped coordinator-mediated repair transition. It must require
an exact task revision and exact retained key, require an open/unowned task with
an empty branch, clear only the stale key, and reject active claims, non-empty
branches, mismatched keys, stale revisions, malformed identities, and any
attempt to repair a different task. Preserve fail-closed binding and all
authority/lease invariants; do not add a general metadata editor or alter ASB.

The repair owns the upstream CLI/runtime, public documentation, positive and
negative contract tests, formal/quality gates where applicable, independent
exact-head review, signed DCO publication, immutable release evidence, and a
downstream handoff naming the exact release/source commit.
