Wire series membership into Coordinator lifecycle transitions. Each member
released `done` emits exactly one idempotent issue update with AR identity,
accepted evidence reference/digest, exact merged/release identity where
applicable, and remaining work. Reopen, supersession, failure and rollback
must publish corrected status.

Only the declared finalizer can close the issue, and only if every required
member is done with accepted evidence, dependencies are satisfied, exact-head
qualification is current, and the live issue still matches. The final comment
must list completed ARs, implementation/release and CI evidence, exclusions and
follow-ups. Ambiguous external effects are typed reconciliation states, never
blind retries or assumed success.
