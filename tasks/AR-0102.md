## Outcome

Every formal run receives a unique, configured working directory, checks its
available capacity before launch, observes time/storage limits while running,
and emits a typed, compact receipt when a resource budget is exceeded.

## Acceptance

- Do not default formal state or temporary files to an uncontrolled shared
  temporary directory when a configured workspace is available.
- Preflight free space, enforce per-tier time and storage budgets, and stop
  safely before host pressure becomes an outage.
- Preserve a bounded diagnostic artifact on failure without treating it as
  successful formal evidence.
- Classify capacity, timeout, tool, and property failures separately; test
  each class with deterministic fixtures.
- Keep all acceptance evidence locally reproducible; external authentication,
  signatures, and independent review are optional, never progression gates.
