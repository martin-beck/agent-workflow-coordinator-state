## Problem statement

Coordinator AR-0085 added a distinct, fail-closed `unblock` transition for an
externally blocked task while preserving pause-snapshot `resume`. Independent
downstream review of the exact merged revision
`ee68fbd31ef5564586e4e81297a175abcaa49c6d` found that the two paths do not
enforce equivalent provenance integrity.

`_session_for_reference` selects the first session record at the requested
revision with `next(...)`, validates only that record's general shape, and
checks only its top-level `trigger=pause` and `status=blocked`. The Git JSONL
decoder also accepts multiple records at one revision and does not bind a
record's `task` field to the requested session file/task. Deterministic
read-only execution against exact merged bytes proved that `resume` accepted
and reopened all of these hostile cases:

1. two pause records with the same exact revision;
2. nested `step_state.status=open` under top-level blocked;
3. nested `step_state.task_revision=6` while requesting revision 7;
4. record `task=AR-8888` returned while resuming `AR-9999`.

The bound downstream authority is Git. SQLite uniqueness does not repair or
justify accepting corrupt Git provenance, and the accepted cases violate the
documented distinction between exact pause restoration and external unblock.

## Required implementation

- Resolve a pause reference by collecting all records at the requested exact
  revision and require exactly one; zero and duplicate matches fail before any
  task, revision, owner, lease, next action, session, projection, or
  publication mutation.
- Require the unique record to bind the requested task ID, top-level
  `trigger=pause` and `status=blocked`, and nested `step_state.status=blocked`
  plus `step_state.task_revision` equal to the requested/current revision.
- Validate task/file identity and duplicate revisions at the appropriate Git
  storage/doctor boundary so corrupted JSONL cannot appear healthy. Preserve
  migration and SQLite parity; do not rely solely on SQLite constraints.
- Keep the positive exact pause snapshot behavior unchanged, including
  `next_action` restoration and one revision increment. Keep AR-0085 external
  `unblock` semantics unchanged and distinct.
- Normalize malformed/ambiguous errors into bounded public-safe diagnostics;
  never echo raw session content or paths.
- Add Git decoder/backend, SQLite, CLI, transition, doctor, migration,
  rollback, projection-failure, stale revision, and concurrent-resume tests.
  Cover the four exact regressions plus missing record, wrong trigger/status,
  cross-task reference, and duplicate histories.
- Extend the lifecycle formal model with absent, unique-valid,
  unique-incoherent, and duplicate pause provenance. Prove only unique-valid
  enables resume, rejected calls stutter, and ownership/CAS/atomicity remain
  intact.
- Compute the complete first-party formal verification closure executed,
  loaded, or hashed by `formal/handoffctl/verify.sh`, including lifecycle,
  binding, lock, run, storage, and recovery modules/configurations plus their
  attestation/evidence inputs. Add that closure to the official vendor set so
  a downstream sync cannot retain and execute stale pre-repair TLA files while
  reporting them as evidence for the new runtime.
- Update embedded documentation and official vendor closure so clean
  downstream development syncs include the repaired implementation, tests,
  formal modules/configurations, verifier, attestation inputs, and evidence
