Create the Coordinator foundation for turning one GitHub issue into a
reviewable AR series. A strict versioned manifest binds the repository,
immutable issue number/URL, privacy-safe issue digest, ordered members,
dependency edges and exactly one declared finalizer. A human or reviewed
planner supplies the structured decomposition; Coordinator validates it and
atomically creates every required AR record. It must reject duplicate issue
bindings, missing finalizers, cycles, cross-project members, incomplete scope,
or a finalizer not ordered after every other member.

Preserve revision CAS, leases, lock ordering, bindings, generated views and
Git/SQLite parity. Do not store issue bodies, tokens, raw comments, private
paths or prompts. This AR creates no GitHub comments or closures.
