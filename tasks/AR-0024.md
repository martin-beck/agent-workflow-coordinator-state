# AR-0024

The v0.3.50 coordinator release exposed a vendor-boundary defect in ASB: the
published vendor helper installs a newer, broader manifest definition while
the same snapshot does not leave every newly required module in the downstream
target. The next verifier therefore fails and the state command cannot start.

Repair the coordinator vendor publication path, not the ASB target. The
published source list, installer, verifier and installed snapshot must agree
and must be transactionally atomic. Preserve immutable release identity,
symlink/path/privacy checks, signed+DCO history and fail-closed behavior.
This AR does not authorize weakening downstream verification or hand-editing a
consumer manifest.
