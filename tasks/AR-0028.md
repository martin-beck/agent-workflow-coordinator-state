# AR-0028

Repair the coordinator-to-ASB vendor boundary. The coordinator vendor helper
currently allowlists formal model, attestation and launcher files that are
owned and qualified by ASB. A coordinator release therefore overwrites ASB
formal contracts and causes the ASB vendor verifier to reject any legitimate
ASB formal repair as a digest mismatch.

Remove only those ASB-owned formal destinations from the coordinator vendor
allowlist and its generated lock contract. Preserve the coordinator runtime,
schemas, tests and documentation that are genuinely vendored. Add positive
tests proving the runtime snapshot remains complete and negative tests proving
ASB formal files are not replaced or admitted through the coordinator vendor
manifest. Update the development documentation to state the ownership split.

Run the complete coordinator gates, review the exact diff, require signed
conventional DCO commits and publish a new immutable release only after all
checks pass. The release must be consumable offline by ASB and must not alter
ASB qualification semantics, resource limits or signing policy.
